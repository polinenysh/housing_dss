# Выбор жилья в Москве

Приложение сравнивает покупку квартир и домов в Москве с помощью AHP, TOPSIS и анализа Парето. Для каждого объекта рассчитывает аннуитетную и дифференцированную ипотеку.

## Запуск через Docker

Нужен запущенный Docker Engine и Docker Compose, например в составе Docker Desktop. Python и библиотеки на компьютере устанавливать не требуется. Откройте терминал в папке проекта и выполните:

```bash
docker compose up --build -d --wait
```

После успешного запуска откройте **http://localhost:8501**. Команда `--wait` дожидается готовности сервера, браузер открывается вручную. При первой сборке Docker загружает базовый образ и зависимости из интернета. Подготовленная выборка уже входит в контейнер. При следующих запусках образ и зависимости используются повторно.

Остановка и удаление контейнера приложения:

```bash
docker compose down
```

Просмотр состояния и журналов:

```bash
docker compose ps
docker compose logs -f app
```

После изменения кода или CSV повторите команду запуска с `--build`. На компьютере порт 8501 должен быть свободен: обычный запуск через Python на том же порту нужно предварительно остановить.

Если Docker Compose недоступен, можно использовать Docker CLI:

```bash
docker build -t housing-dss:local .
docker run --rm --name housing-dss-app -p 127.0.0.1:8501:8501 housing-dss:local
```

Во втором случае терминал показывает журнал приложения. Для остановки нажмите Ctrl+C. Команды сборки и запуска выполняются в выбранном локальном Docker-контексте. Проверить его можно командой `docker context show`; используйте контекст, предназначенный для этого учебного приложения.

### Как устроен контейнер

`Dockerfile` использует официальный `python:3.12-slim-bookworm`, зафиксированный digest многоархитектурного образа. Проверенный ARM64-образ содержит Python 3.12.16, pip и необходимые системные библиотеки. Установка зависимостей использует готовые бинарные пакеты из существующего `requirements.txt`. Компиляторы, Git и curl не добавляются.

Процесс работает от пользователя `appuser`. Внутри контейнера Streamlit слушает `0.0.0.0:8501`, а `compose.yaml` публикует порт только на `127.0.0.1` компьютера. Аргумент командной строки в контейнере перекрывает значение из `.streamlit/config.toml`; обычный запуск через Python сохраняет адрес `127.0.0.1`. [Приоритет настроек Streamlit](https://docs.streamlit.io/develop/concepts/configuration/options).

Healthcheck использует стандартную библиотеку Python и проверяет `/_stcore/health`. Он определяет готовность сервера, а корректность вычислений и интерфейса проверяют существующие тесты проекта. `.dockerignore` разрешает передавать в сборку только код приложения, зависимости, подготовленный CSV и конфигурацию. Локальные окружения, тесты, Git и секреты в образ не копируются. Загрузка пользовательского CSV и скачивание результатов работают через браузер, подключать папки компьютера к контейнеру не требуется.

## Запуск без Docker

Нужен Python 3.11–3.13. Проверено на Python 3.12.14, macOS Apple Silicon. Откройте терминал в папке проекта.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

В Windows вместо `source` выполните `.venv\Scripts\activate`.

Приложение открывается по адресу http://127.0.0.1:8501. Зависимости устанавливаются один раз. Для последующих запусков достаточно активировать окружение и выполнить последнюю команду. Приложение слушает только локальный адрес. Для работы с подготовленной выборкой интернет не нужен. Он нужен при первоначальной установке пакетов и для перехода на исходные объявления.

## Работа с приложением

1. Выберите «Квартира и дом», «Квартира» или «Дом». По умолчанию показаны оба типа.
2. Укажите максимальную цену, минимальную площадь, местность и доступность станции. Пустой список местностей означает отсутствие этого ограничения.
3. На вкладке «Предпочтения AHP» сравните важность трёх критериев по шкале Саати: цена, предпочтение района, время до станции. По умолчанию цена важнее района в 3 раза, цена важнее времени в 5 раз, район важнее времени в 2 раза. Начальная матрица проходит порог CR ≤ 0,10.
4. Задайте предпочтения местностей от 1 до 9. Начальное значение 5 одинаково для всех. Эти оценки задаёт пользователь, они не получены от Циан. При одинаковых оценках районы не различаются этим критерием.
5. Сравните рейтинги AHP и TOPSIS. Отметка Парето показывает отсутствие другого объекта, который не хуже по всем трём критериям и лучше хотя бы по одному.
6. Настройте первоначальный взнос, годовую ставку и срок. На вкладке «Ипотека» выберите объект и сравните платежи, проценты и остаток долга.
7. Скачайте рейтинг CSV, ипотечные графики CSV и параметры сценария JSON. CSV содержит исходные показатели, пользовательские оценки и веса, а также параметры ипотеки.

По умолчанию бюджет равен 50 млн рублей, минимальная площадь 0 м², допустимое время до станции 60 минут, взнос 20%, срок 20 лет и ставка 14%. Ставка 14% — учебное допущение, а не актуальное банковское предложение. Площадь используется как ограничение и не включена в трёхкритериальный рейтинг. Полная цена предпочтительнее цены за м², поскольку отражает бюджет покупки.

## Данные

`data/cian_moscow.csv` содержит **104 реальных объявления Циан: 78 квартир и 26 домов**. Поля прочитаны 28 и 31 октября 2026 года: 42 карточки через браузер, 62 через публичный веб-индекс. У всех записей есть станция и время до неё, поэтому при начальных фильтрах в рейтинг входят все 104 объекта. Индексированные копии могут отставать от текущей версии объявления. Для каждого сохранены прямой URL, источник полей, дата наблюдения и примечания. Подробности и ограничения находятся в `data/README.md`. `source_observations.json` сохраняет тот же набор фактических наблюдений для сверки.

Это целевая небольшая выборка для сравнения методов, она не характеризует весь рынок. Цены и доступность могут измениться. Программа не выполняет автоматический сбор или сетевые запросы к Циан. Подготовка выборки не использовала API, учётную запись, контакты продавцов или персональные данные. Наличие объявления не подтверждает его юридическую достоверность.

В карточках указан путь до определённой станции, а не до единой рабочей точки. Пешие пути и поездки транспортом имеют отдельный фильтр. При смешении способов приложение предупреждает о разнице. В расчёты не добавляется выдуманное время ожидания или поездки. Если у загруженной записи нет всех транспортных полей, приложение сохраняет её в исходной таблице и исключает из рейтинга. Источник может содержать разные станции в строке пути и адресном теге: применяется станция, для которой явно указаны время и способ.

Для загрузки собственной выборки используйте те же столбцы, что в комплектном CSV. Максимум 1000 записей и 5 МБ. Числа записываются с точкой, разделитель — запятая. ID уникален, URL строго соответствует типу и ID, транспортные поля заполняются вместе. Текст CSV при экспорте защищён от интерпретации как формула Excel.

## Методы

### AHP

Главный собственный вектор матрицы попарной важности критериев нормируется к сумме 1. Для трёх критериев `CI = (lambda_max - 3) / 2`, `CR = CI / 0.58`. При `CR > 0.10` интерфейс показывает предварительный статус и просит уточнить оценки.

Локальные приоритеты альтернатив соответствуют согласованным матрицам отношений наблюдаемых значений: `x_i/x_k` для предпочтения района и `x_k/x_i` для цены и времени. Поэтому они вычисляются нормированием прямых либо обратных значений. Итог — сумма локальных приоритетов с весами критериев. Ограничение шкалы 1–9 и обратных значений применяется к субъективной матрице критериев. Матрицы объективных отношений этим ограничением не ограничиваются.

### TOPSIS и Парето

TOPSIS использует евклидову нормировку столбцов, веса AHP, лучшие и худшие значения с учётом направления критериев и близость `D_minus / (D_plus + D_minus)`. Для одного объекта или полностью одинаковых объектов результат равен 0,5. Веса двух методов одинаковые, поэтому сравнивается влияние способа агрегирования. Это не два независимых источника экспертных предпочтений.

Парето сравнивает исходные три показателя и не зависит от весов. Объекты с этим статусом остаются в общей таблице. Ранги плотные: равные результаты имеют одно место, последующие ранги идут без пропусков. При изменении состава выборки нормировка и относительные оценки могут измениться.

### Ипотека

Месячная ставка равна годовой ставке в процентах / 1200. Аннуитет до округления: `P*r*(1+r)^N / ((1+r)^N-1)`. В дифференцированном графике основной долг распределяется равномерно, проценты начисляются на остаток. При нулевой ставке обе схемы делят долг на срок.

Расчёт использует Decimal с округлением HALF_UP до копеек по каждому месяцу и корректировкой последнего платежа. В дифференцированной схеме копейки распределяются через накопленную целевую сумму погашения. Пустой кредит при взносе 100% даёт нулевые платежи. Проценты означают переплату сверх суммы кредита. Итоговая цена покупки со взносом равна цене объявления плюс проценты.

Модель учитывает фиксированную ставку, равные месячные периоды, основной долг и проценты. Страхование, комиссии, налоги, ремонт, содержание дома, досрочные погашения и реальный календарь банковских начислений не учтены. Модель помогает сравнить сценарии при одинаковых предположениях и не оценивает одобрение кредита.

```text

app.py                       Интерфейс Streamlit
housing_dss/data.py           Загрузка, проверка и экспорт CSV
housing_dss/decision.py       AHP, TOPSIS и Парето
housing_dss/mortgage.py       Ипотечные графики
housing_dss/workflow.py       Фильтры и сводные расчёты

data/source_observations.json Фактические наблюдения
data/README.md               Происхождение и ограничения данных
tests/                       Математические и интерфейсные проверки
```

## Проверка

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Тесты проверяют ручные числовые примеры, согласованность AHP, направления критериев, доминирование и равенства, сохранение суммы долга, округление, нулевую ставку, полную оплату, строгую загрузку CSV и работу фильтров. Интерфейс проверяется официальным `Streamlit AppTest` в текущем Python-процессе.
