# Выборка объявлений Циан

`cian_moscow.csv` содержит **104 реальных объявления продажи жилья в Москве**, включая Новую Москву: **78 квартир и 26 домов**. Поля прочитаны **28 и 31 октября 2026 года**: 42 карточки в обычном браузере и 62 карточки через публичный веб-индекс. API не использовался. Это целевая выборка для сравнения методов, а не репрезентативный срез рынка недвижимости.

ID объявлений уникальны. В комплект включены объекты с полной парой «станция — время/режим»; все 104 записи проходят начальные фильтры цены 50 млн рублей и времени 60 минут. Объявления участков, строительного подряда, апартаментов, заведомо недостроенных и неподходящих для круглогодичного проживания объектов в расширение не включены.

`source_observations.json` сохраняет те же фактические поля и исходный тип объекта. В файлах нет персональных контактов, имён продавцов и скопированных описаний объявлений.

## Значение полей

| Поле | Содержание |
| --- | --- |
| `listing_id` | Идентификатор объявления Циан; хранится строкой |
| `property_type` | `Квартира` или `Дом`; коттеджи включены в дома |
| `price_rub`, `area_m2` | Цена в рублях и площадь в м², отображённые в карточке |
| `rooms` | Число комнат квартиры; `0` означает студию. У всех домов поле пустое |
| `location` | Адрес или местность из карточки с префиксом «Москва» |
| `district` | Группа местности для настройки пользовательских предпочтений; не всегда административный район |
| `metro` | Первая отображённая станция, включая МЦК, МЦД и железнодорожные станции; название поля сохранено для приложения |
| `travel_minutes` | Отображённое время до этой станции |
| `transport_mode` | `walking` — пешком; `transport` — на транспорте, без уточнения его вида |
| `source_url` | Прямая ссылка на объявление |
| `observed_at` | Дата чтения карточки или индексированной копии: `2026-10-28` либо `2026-10-31` |
| `verification_level` | `live_catalog`: видимая карточка в браузере; `indexed_catalog`: публичная индексированная копия |
| `evidence_url`, `evidence_note` | Ссылка на страницу карточки и правило фиксации полей |

## Правила фиксации и использования

Приоритет отдан структурированным полям карточки. При первичном сборе 28 октября зафиксированы следующие расхождения и уточнения:

| ID объявления | Значение, принятое в выборке | Расхождение или уточнение |
| --- | --- | --- |
| [334096948](https://www.cian.ru/sale/flat/334096948/) | 7 минут пешком | В описании указано 6 минут |
| [332779956](https://www.cian.ru/sale/flat/332779956/) | 8 минут пешком | В названии объявления указано 5 минут |
| [329195716](https://www.cian.ru/sale/flat/329195716/) | 4 минуты пешком | В описании указано 3 минуты |
| [332739143](https://www.cian.ru/sale/flat/332739143/) | Площадь 42 м² | В описании указано 41,9 м² |
| [333640760](https://www.cian.ru/sale/flat/333640760/) | Белокаменная (МЦК), 15 минут пешком | Уточнён вид станции; число минут сохранено |
| [335262081](https://www.cian.ru/sale/flat/335262081/) | Багратионовская, 14 минут пешком | Адресный тег содержит Фили; взята первая пара станции и времени |
| [334208969](https://www.cian.ru/sale/flat/334208969/) | Цена квартиры 32 000 000 рублей | Опциональная кладовая за дополнительные 2 000 000 рублей в цену не включена |

Число спален не считается числом комнат, поэтому неизвестное число комнат домов оставлено пустым.

Станция и время взяты из **первой отображённой пары «станция — время/режим»**, а не из адресного тега «м.». Будущие станции не использованы. Это данные объявления о времени до станции; они не получены маршрутизатором и не описывают дорогу до работы. Пешую доступность и поездку на транспорте следует различать отдельным фильтром: одинаковое число минут имеет разный смысл.

Оценки района в исходной выборке отсутствуют. `district_score` — пользовательская настройка приложения, а не факт Циан: исходно всем местностям присваивается одинаковая нейтральная оценка **5**. Ставки и другие параметры ипотеки также не являются полями объявлений и задаются пользователем отдельно.

Прочтение карточки не подтверждает содержание полной detail-страницы, права на объект или юридическую чистоту сделки. Цена и наличие предложения могут измениться после указанной даты наблюдения; перед практическим использованием нужно открыть исходное объявление. Одинаковый адрес сам по себе не доказывает, что два разных ID обозначают один объект: сравнение ведётся по объявлениям.

CSV использует UTF-8 и разделитель-запятую. Пустое числовое поле означает неизвестное значение, а не ноль. Для `indexed_catalog` дата означает день чтения индексированной копии, а не актуализацию объявления. Копии каталогов домов имели метки кэша last week или last month; доступность объектов в реальном времени по ним не подтверждалась. Метод чтения и уточнения сохранены в `evidence_note`; значения транспорта не достраивались предположениями.
